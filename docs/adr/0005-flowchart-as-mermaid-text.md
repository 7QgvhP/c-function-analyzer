# 0005. フローチャートは Mermaid のテキストとして出力する

- ステータス: Accepted
- 日付: 2026-10-09（v3.7.0 でフローチャートの出力を追加）

## 背景（Context）

関数の構造をフローチャートで見たい。

## 決定内容（Decision）

関数の制御構造を Mermaid 記法のテキストにして、クリップボードにコピーする。拡張機能の画面内では図にしない。

## 理由と検討した代替案（Consequences / Alternatives）

- 画面内で図にするには、描画ライブラリの同梱と、Webview のセキュリティ設定（CSP）の緩和が必要になる（旧 README より）。
- GitHub・Notion・mermaid.live など、Mermaid に対応した場所に貼り付ければ図になる。
- 検討した代替案: 拡張機能の画面内での描画。上記の理由で採用しない。
