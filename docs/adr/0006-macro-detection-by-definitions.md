# 0006. マクロかどうかを、収集した定義だけで判定する

- ステータス: Accepted
- 日付: 2026-10-06（v3.5.0）

## 背景（Context）

識別子がマクロか変数・関数かは、名前が大文字かどうかでは決まらない（`extern int GLOBAL_COUNTER;` は変数、`#define hoge 10` はマクロ）。

## 決定内容（Decision）

収集した定義（`#define`、`enum` の列挙子、変数・関数の宣言、型の定義）だけで判定し、名前の大小は使わない。型として定義されている名前は表示しない。`#define` と宣言が同名で存在する場合は、マクロを優先する。

## 理由と検討した代替案（Consequences / Alternatives）

- 名前の付け方の習慣に左右されずに判定できる。
- `#define` と宣言が同名の場合にマクロを優先するのは、プリプロセッサが先に展開するため。
- 検討した代替案: 名前が大文字だけならマクロとみなす方式（v2.10 までは主な判定、v2.11.0〜v3.4 は定義が見つからないときの推定。設定 `classifyAllUppercaseAsMacros`）。v3.5.0 で削除した。
