# 0003. 定義位置を VS Code の定義プロバイダで求める

- ステータス: Accepted
- 日付: 2026-08-04（v3.0.0）

## 背景（Context）

型名・コメント・定義値を表示するには、識別子の定義位置が必要。インクルードパスやマクロ定義（`-D`）はビルドの構成で変わり、同名のヘッダを切り替える構成もある。

## 決定内容（Decision）

参照位置で VS Code の定義プロバイダ（F12 と同じもの。C/C++ 拡張の IntelliSense）を呼び、返った定義位置から型名・コメント・定義値を読み取る。候補が複数ある場合は `excludePaths` で絞り込み、残れば先頭を採用して注意を表示する。

## 理由と検討した代替案（Consequences / Alternatives）

- 実際のビルド構成（IntelliSense の設定）に基づく定義位置が得られる。
- C/C++ 拡張に依存する。IntelliSense が動かない環境では、型名が `(推定)` のままになる。原因の切り分けのため、定義ジャンプの診断を用意した。
- 検討した代替案: 自前で `#include` を辿る方式（v2.x まで）。v3.0.0 で置き換えた。置き換えにより、インクルードの深さの上限、同名ファイルの取り違え、Shift-JIS の文字化けは、原理的に起きなくなった（CHANGELOG v3.0.0 より）。
