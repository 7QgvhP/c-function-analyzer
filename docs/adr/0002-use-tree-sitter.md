# 0002. 正規表現ではなく tree-sitter で構文解析する

- ステータス: Accepted
- 日付: 2026-06-05（v1.0.0）

## 背景（Context）

関数の中で、変数が読まれているか書き込まれているか、どの関数を呼んでいるかを判定する必要がある。C の記述には、多重ポインタ・多次元配列・構造体メンバ・関数ポインタなど、文字列のパターンでは判別しにくいものがある。

## 決定内容（Decision）

`web-tree-sitter` と C 言語パーサーの WASM で AST を作り、構文に基づいて判定する。修飾子マクロでパースが崩れる箇所は、解析の前に修復する（`macroRepair.ts`）。

## 理由と検討した代替案（Consequences / Alternatives）

- 多重ポインタ・多次元配列・構造体メンバ・関数ポインタといった記述も、正しく判別できる。
- マクロは展開しないため、制御構造や型をマクロで隠している記述は判別できないことがある。
- 検討した代替案: 正規表現による判定。上記の記述を判別できないため採用しない。
