# 0004. アドレス渡しは、呼び出し先の宣言を見ずに入出力の両方にする

- ステータス: Accepted
- 日付: 2026-09-29（v3.3.0）

## 背景（Context）

関数呼び出しの引数にアドレスを渡している変数（`set_value(&g_count)`、配列名）は、呼び出し先が書き込む可能性がある。

## 決定内容（Decision）

アドレスを渡しているグローバル変数・ポインタ引数のメンバ・配列名は、入力と出力の両方に表示し、説明欄に「アドレス渡し」と示す。呼び出し先のプロトタイプ宣言（`const` の有無）は見ない。ローカル変数・値渡し引数・ポインタ変数をそのまま渡す場合は対象外。

## 理由と検討した代替案（Consequences / Alternatives）

- 宣言が引けるかどうかで結果が変わらないようにする（インクルード設定の不備や暗黙の宣言がある環境では、宣言を引けないことがある）。
- 実際には読み取るだけの関数（`print_value(&g_count)` など）でも、出力に表示される。
- 検討した代替案: 呼び出し先のプロトタイプの `const` を見て判定する。上記の理由で採用しない。
