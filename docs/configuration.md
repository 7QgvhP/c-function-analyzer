# 設定リファレンス

VS Code の設定で変更する。環境変数とコマンドラインオプションはない。

## 設定ファイル

VS Code の設定（`settings.json`）に書く。

| 名前 | 説明 | 型 | デフォルト値 | 必須 |
|---|---|---|---|---|
| `c-function-analyzer.macroDisplay` | マクロ変数・マクロ関数を、独立した分類に表示するか（`separate`）、入力変数・出力変数・呼び出し関数に含めるか（`merged`）。解析結果画面の「マクロ表示」ボタンでも切り替えられる | 文字列（`separate` / `merged`） | `separate` | いいえ |
| `c-function-analyzer.excludePaths` | 定義へのジャンプ先から除外する場所（配下すべてが対象外）。ディレクトリ指定とフォルダ名指定の2通り | 文字列の配列 | `[]` | いいえ |

## excludePaths の書き方

`excludePaths` は2通りの書き方を受け付ける。どちらも**配下すべて**がジャンプ先の候補から外れる。

| 書き方 | 判定 | 例 |
|---|---|---|
| **ディレクトリ指定**<br>（`/` `\` を含む、または絶対パス） | その場所ちょうど1つ | `"legacy/old_hed"`、`"C:/SDK/deprecated"` |
| **フォルダ名指定**<br>（区切り文字を含まない） | ワークスペース内で、名前にその文字列を**含む**フォルダすべて | `"variantB"` |

同じ命名のフォルダがプロジェクト内の複数箇所に散らばっている場合は、フォルダ名指定が有効である。

```
proj/
├─ control/variantB/       →  除外
├─ control/sub/variantB/   →  除外（階層が深くても一致）
├─ hed/variantB_old/       →  除外（部分一致）
└─ hed/variantA/           →  残る
```

```json
{
  "c-function-analyzer.excludePaths": ["variantB"]
}
```

- 大文字・小文字は区別しない
- 判定対象はフォルダ名のみである。ファイル名（`variantB.h`）は除外されない
- ワークスペース外のパスは、フォルダ名指定の対象外である
- **部分一致**のため、意図しないフォルダに一致しないか確認する（`"old"` は `goldmine` にも一致する）。ちょうど1つのフォルダだけを除外したい場合は `"./variantB"` のように区切り文字を付けてディレクトリ指定にする

除外した結果、候補が1件も残らなかった場合は「定義なし」として扱う（型名は `(推定)`、「定義へ」ボタンは表示しない）。
